# Deenadhayalan - Personal Portfolio

A sleek, modern developer portfolio website built with clean **HTML5, CSS3, and Vanilla JavaScript**, featuring a custom **crimson/red and obsidian dark theme**.

---

## 🚀 Quick Start

1. Open the project folder in VS Code or your file explorer.
2. Double-click `index.html` to open it directly in any browser (Chrome, Edge, Firefox, Brave, Safari).
3. Alternatively, if using VS Code, use the **Live Server** extension to launch with hot-reload.

---

## 🎨 Theme & Design Highlights

- **Color Palette**: Cyber Crimson & Obsidian Dark Theme (`#ff2a4b`, `#dc2626`, `#0a0b0f`, `#12131a`).
- **Typography**: Google Fonts (*Plus Jakarta Sans* for modern readability, *JetBrains Mono* for code aesthetics).
- **Icons**: Font Awesome 6 CDN.
- **Components**:
  - Glassmorphic Sticky Navigation with mobile drawer and active scrollspy.
  - Interactive Hero Section with live typewriter effect and interactive code card.
  - Quick statistics strip with animated number counting.
  - About Me grid with glowing avatar ring, quick info cards, and core values.
  - Technical Toolkit categorizing Frontend, Core Programming, Backend, and Tools.
  - Animated proficiency progress meters.
  - Filterable Featured Projects (All, Web Apps, Algorithms, Tools).
  - Academic & Learning Timeline highlighting Karpagam College (CSE).
  - Interactive Contact Form with real-time field validation and toast alert.
  - Back to top floating button.

## ✏️ How to Customize

- **Email & Social Links**: Update the `mailto:` and `href` attributes in the contact section of `index.html` with your actual GitHub, LinkedIn, and social profiles.
- **Projects**: Edit project descriptions, live demo links, and GitHub repositories in the `<section id="projects">` section of `index.html`.
- **Photo**: You can replace the `<i class="fa-solid fa-user-gear">` icon in `.avatar-inner` with an `<img>` tag of your personal photo (e.g., `<img src="profile.jpg" alt="Deenadhayalan">`).
